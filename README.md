## Why not on GitHub anymore?

The old version of this README asked "Why Blog on Github?" and answered that I
wanted to control my own content and write markdown in git without running a
server. That reasoning was right, and it is exactly why the blog is not here
anymore. Writing on someone else's platform is a rental. My posts now live in
the same repository as the rest of my site, get built by one command, and are
served from a machine I control. Same markdown, same git, one less landlord.

See [Keep it Simple, Stupid](https://cmyers.org/blog/keep-it-simple-stupid-kiss/)
for the longer version of that story.
